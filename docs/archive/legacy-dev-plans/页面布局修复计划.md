# 页面布局修复计划

> **版本**: v1.0  
> **日期**: 2026-03-24  
> **目标**: 修复编单页面左侧空位问题，删除底部操作栏

---

## 一、问题分析

### 1.1 当前问题

1. **左侧空位问题**
   - 页面使用了 `sidebar-open` 类来控制布局
   - 当侧边栏关闭时，左侧仍有空位
   - CSS 中 `.sidebar-open` 会调整 `.timeline-container` 的宽度

2. **底部操作栏问题**
   - 存在 `bottom-action-bar` 组件（第459-513行）
   - 包含历史记录、锁定/解锁、保存、提交按钮
   - 需要完全删除

### 1.2 相关代码位置

**模板部分**:
- 第2行: `<div class="create-schedule-page" :class="{ 'sidebar-open': sidebarOpen }">`
- 第432-436行: `<BroadcastPlanSidebar>` 组件
- 第439-450行: 右侧浮层按钮
- 第459-513行: `bottom-action-bar` 底部操作栏

**脚本部分**:
- 第782行: `const sidebarOpen = ref(false)`
- 第1031行: `sidebarOpen.value = !sidebarOpen.value`

**样式部分**:
- 第1502-1516行: `.sidebar-open` 相关样式
- 第2118行: `left: var(--xnews-sidebar-width);`

---

## 二、修复步骤

### 步骤 1：删除底部操作栏

**任务 1.1**: 删除模板中的 `bottom-action-bar`（第459-513行）

**任务 1.2**: 删除相关样式

### 步骤 2：修复左侧空位

**任务 2.1**: 移除 `sidebar-open` 类的动态绑定
- 将 `:class="{ 'sidebar-open': sidebarOpen }"` 移除

**任务 2.2**: 调整 `.timeline-container` 样式
- 确保宽度为 100%
- 移除与侧边栏相关的宽度计算

**任务 2.3**: 删除右侧边栏和浮层按钮
- 删除 `BroadcastPlanSidebar` 组件
- 删除浮层按钮

### 步骤 3：清理无用代码

**任务 3.1**: 删除 `sidebarOpen` 相关变量和方法

**任务 3.2**: 删除 `BroadcastPlanSidebar` 组件引用
