## 阶段四：接口层与数据（第7-8天）

### Day 7：编排代理接口层 + 数据服务

**目标**：建立标准交互接口和数据服务

**任务清单**：

1. **创建目录结构**
   ```
   src/services/orchestration/
   ├── interfaces/
   │   ├── readInterfaces.ts
   │   ├── previewInterfaces.ts
   │   ├── executeInterfaces.ts
   │   └── explainInterfaces.ts
   └── dataService.ts
   ```

2. **编排数据服务** `src/services/orchestration/dataService.ts`
   - 频道信息获取（getChannelInfo）
   - 播出版面获取（getLayoutReference）
   - 历史编排获取（getHistorySchedules）
   - 节目库查询（queryProgramLibrary）
   - 固定播出项获取（getFixedItems）
   - 数据缓存机制

3. **读取类接口** `src/services/orchestration/interfaces/readInterfaces.ts`
   - `getGenerationContext(channelId, date)` - 获取生成上下文
   - `getProgramDetails(programCode)` - 获取节目详情
   - `queryRemainingGaps()` - 查询剩余空窗
   - `queryCandidatesByMultiSource(params)` - 多源检索候选
   - `getRecentScheduleReference(channelId, date, days)` - 获取历史参考
   - `getLayoutReference(channelId, date)` - 获取版面参考

4. **预演类接口** `src/services/orchestration/interfaces/previewInterfaces.ts`
   - `previewMaterializeFillItem(params)` - 预演物化
   - `previewCommand(command)` - 预演命令
   - `simulateBatchCommand(commands)` - 模拟批量命令

5. **执行类接口** `src/services/orchestration/interfaces/executeInterfaces.ts`
   - `executeCommand(command)` - 执行命令
   - `validateSchedule(scope)` - 校验编排
   - `executeRepairAction(action)` - 执行修复

6. **解释类接口** `src/services/orchestration/interfaces/explainInterfaces.ts`
   - `explainCandidateSelection(candidateId)` - 解释候选选择
   - `summarizeValidationIssues(scope)` - 汇总校验问题
   - `explainCommand(command)` - 解释命令

**验收标准**：
- [ ] 数据服务能获取所有必要上下文
- [ ] 所有接口层实现
- [ ] 缓存机制有效
