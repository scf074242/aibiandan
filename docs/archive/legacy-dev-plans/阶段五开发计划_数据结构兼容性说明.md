## 2. 新增的类型定义（仅用于编排系统内部）

### 新增文件：`src/types/orchestration.ts`

这些类型是**编排系统内部使用**的，不影响现有数据结构：

| 类型 | 用途 | 与现有数据关系 |
|------|------|----------------|
| `TaskClassification` | 任务判别结果 | 独立，不影响 ScheduleItem |
| `GapInfo` | 空窗信息（编排用） | 独立，运行时计算生成 |
| `PlanningSession` | 编排会话状态 | 独立，管理编排过程 |

| `ValidationReport` | 校验报告 | 独立，校验结果 |
| `MaterializeResult` | 物化结果 | **输出为 ScheduleItem** |
| `OrchestrationProgress` | 编排进度 | 独立，UI 展示用 |

### 关键兼容点

**`ScheduleItemSnapshot` 与 `ScheduleItem` 的映射：**

```typescript
// 编排系统内部使用的快照
interface ScheduleItemSnapshot {
  id: string
  programCode: string
  programName: string
  startTime: string
  endTime: string
  duration: number
  programType: string
  sequence: number
}

// 物化器输出转换为现有 ScheduleItem
function convertToScheduleItem(
  snapshot: ScheduleItemSnapshot
): ScheduleItem {
  return {
    id: snapshot.id,
    programCode: snapshot.programCode,
    programName: snapshot.programName,
    startTime: snapshot.startTime,
    endTime: snapshot.endTime,
    duration: snapshot.duration,
    businessType: snapshot.programType as any,
    sortOrder: snapshot.sequence,
    // 其他字段使用默认值
    sourceType: 'recorded',
    materialStatus: 'pending',
    isLocked: false,
    isUnlinkedProduct: false,
    isMaterialInfoEmpty: true,
  }
}
```
