## 阶段五：UI 重构与集成（第9-10天）

### Day 9：UI 组件重构

**目标**：适配新架构的界面组件

**任务清单**：

1. **重构编排进度组件** `src/components/orchestration/OrchestrationProgress.vue`
   - 显示空窗处理进度（总/待处理/处理中/已完成/失败）
   - 显示当前处理空窗信息（时间段、时长）
   - 显示三级回退状态（当前回退级别、尝试次数）
   - 显示修补轮次（当前轮次/最大轮次）
   - 进度条和百分比
   - 时间预估（预计完成时间）
   - 最近日志滚动显示

2. **创建任务模式选择器** `src/components/orchestration/TaskModeSelector.vue`
   - 6种任务模式选择：
     - full_generate（完整生成）
     - partial_generate（局部补排）
     - micro_edit（局部微调）
     - validate_only（仅校验）
     - repair_only（仅修复）
     - clarify（澄清）
   - 模式说明卡片（图标+描述）
   - 智能模式推荐（基于当前节目单状态）
   - 风险等级提示

3. **创建空窗可视化组件** `src/components/orchestration/GapVisualizer.vue`
   - 时间轴展示（24小时时间线）
   - 空窗状态可视化：
     - 待处理（灰色）
     - 处理中（蓝色动画）
     - 已完成（绿色）
     - 失败（红色）
   - 点击跳转到对应位置
   - 空窗详情悬浮提示（时间段、时长、约束）
   - 已填充节目显示

4. **重构对话面板** `src/components/dialogue/ChatPanel.vue`
   - 澄清模式交互（当任务判别为 clarify 时）
   - 显示命令预览（执行前展示影响范围）
   - 显示解释信息（候选选择解释、校验问题解释）
   - 自然语言输入框
   - 消息历史记录
   - 快捷操作按钮

**验收标准**：
- [ ] 进度组件显示空窗级进度
- [ ] 任务模式选择器可用
- [ ] 空窗可视化正确展示
- [ ] 对话面板支持澄清模式

### Day 10：集成测试与优化

**目标**：端到端集成和性能优化

**任务清单**：

1. **集成测试**
   - 完整生成流程测试（从空表到完整编排）
   - 局部补排流程测试（只填充部分空窗）
   - 微调命令测试（插入/删除/替换/移动）
   - 回退机制测试（触发三级回退）
   - 修补机制测试（校验失败后的自动修复）
   - 人工介入流程测试（会话级回退）

2. **性能优化**
   - Prompt 缓存优化（相同上下文复用）
   - 候选检索缓存（避免重复查询）
   - 上下文复用（减少 LLM 调用次数）
   - 异步处理（非阻塞编排流程）
   - 防抖节流（用户输入处理）

3. **边界情况处理**
   - 空节目单处理（从零生成）
   - 全天空窗处理（大空窗分割）
   - 无候选情况处理（提示人工选择）
   - 连续校验失败处理（达到上限转人工）
   - LLM 响应超时处理（重试或降级）
   - 网络异常处理（断线重连）

4. **文档更新**
   - API 文档更新（所有接口说明）
   - 使用手册更新（用户操作指南）
   - 架构图更新（最新架构设计）
   - 开发文档（二次开发指南）

**验收标准**：
- [ ] 所有核心流程端到端跑通
- [ ] 性能满足使用要求（响应时间 < 2s）
- [ ] 文档同步更新
