# 功能对齐清单

更新时间：2026-04-02

## 文档目的

这份文档用于把“需求文档中的功能项”和“当前仓库里的真实实现”对齐。

建议把它理解为一张工作底表：

- 左边是需求目标
- 中间是当前状态
- 右边是下一步缺口

它不替代需求文档，也不替代测试清单。

## 状态说明

- 已实现：主流程已落地，可在当前仓库中运行或演示
- 部分实现：有代码、有入口或有服务层基础，但还没有形成完整闭环
- 未实现：需求文档中有定义，但当前仓库中未形成实际能力

## 当前最接近可交付演示的能力

如果只看“现在最适合演示什么”，建议聚焦这 4 项：

1. 频道与日期选择 + 串联单主编辑表格
2. AI 对话式微调
3. 基于版面文件导入的编排上下文切换
4. 风险摘要、高亮与基础校验反馈

## 当前最明显的缺口

如果要继续向需求文档靠齐，最明显的差距在这里：

1. 独立的编排进度面板
2. 独立的校验报告面板
3. 版面参考对比面板
4. 导出与历史记录
5. 节目库生成脚本与真实种子数据闭环
