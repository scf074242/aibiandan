## 布局规格

| 区域 | 宽度 | 说明 |
|------|------|------|
| 节目单编辑区 | 80% | 主要内容，支持横向滚动 |
| AI助手侧边栏 | 20% | 固定宽度，ChatPanel |
| 编排进度面板 | 100% | 底部可收起面板 |

```css
.ai-sidebar {
  width: 20%;
  min-width: 280px;  /* 最小宽度 */

}
```
