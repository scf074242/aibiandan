## 四、测试步骤

### 快速测试流程

1. **访问页面**
   ```
   http://localhost:5173/broadcast-plan/create
   ```

2. **配置 API Key**
   - 点击"AI 智能编排"按钮
   - 选择"AI 配置" Tab
   - 输入 Kimi API Key
   - 点击"测试连接"

3. **开始编排**
   - 返回"编排进度" Tab
   - 点击"开始编排"
   - 观察进度更新

4. **测试对话**
   - 点击"AI 助手"按钮（如有）
   - 输入测试指令
