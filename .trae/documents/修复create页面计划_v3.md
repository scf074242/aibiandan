├─────────────────────────────────────────────────────────────────┤
│  工具栏（添加节目、从计划导入、显示版面、AI智能编排按钮）            │
├──────────────────────────────┬──────────────────────────────────┤
│                              │                                  │
│                              │   🤖 AI 助手侧边栏                │
│    节目单编辑表格             │   ┌─────────────────────────┐    │

│                              │   └─────────────────────────┘    │

## 交互流程

1. **用户点击 "AI 智能编排" 按钮** → 右侧滑出 Chat 侧边栏
2. **用户在对话框输入需求** → 例如："帮我填充所有空窗"
3. **LLM 自动分析** → 调用 taskClassifier 得出任务模式（如 partial_generate）
4. **显示命令预览** → 用户确认后执行
5. **底部显示编排进度** → 实时更新空窗处理状态
