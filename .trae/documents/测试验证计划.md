## 二、测试步骤

### 步骤 1：项目编译检查

**任务 1.1**: 运行项目编译
```bash
npm run dev
```

**验证点**:
- [ ] 项目成功启动
- [ ] 没有编译错误
- [ ] 没有 TypeScript 类型错误（针对新代码）

### 步骤 2：页面功能验证

**任务 2.1**: 验证 AI 按钮显示
- [ ] 打开编单页面
- [ ] 确认"AI 智能编排"按钮显示在工具栏
- [ ] 确认按钮样式正确（渐变背景色）

**任务 2.2**: 验证编排抽屉
- [ ] 点击"AI 智能编排"按钮
- [ ] 确认抽屉从右侧滑出
- [ ] 确认包含两个 Tab 页：编排进度、AI 配置
- [ ] 确认编排进度面板显示正常
- [ ] 确认 LLM 配置面板显示正常

**任务 2.3**: 验证配置功能
- [ ] 输入 API Key
- [ ] 选择模型
- [ ] 点击"测试连接"按钮
- [ ] 确认连接成功

### 步骤 3：LLM 功能测试

**任务 3.1**: 配置 LLM
- [ ] 配置 Kimi API Key
- [ ] 保存配置

**任务 3.2**: 测试编排流程
- [ ] 点击"开始编排"按钮
- [ ] 确认编排进度面板开始更新
- [ ] 确认时段块状态正确显示
- [ ] 确认日志正常输出
- [ ] 等待编排完成

**任务 3.3**: 测试对话功能
- [ ] 打开 AI 对话抽屉
- [ ] 输入测试指令
- [ ] 确认 AI 返回响应

### 步骤 4：修复发现的问题

**可能遇到的问题**:

1. **API Key 无效**
   - 检查 API Key 是否正确
   - 确认网络连接

2. **编排失败**
   - 检查 Prompt 格式
   - 检查 LLM 响应解析
   - 查看浏览器控制台日志

3. **UI 显示问题**
   - 检查组件是否正确导入
   - 检查样式是否冲突
